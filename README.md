# Task 3: Movie Recommendation System

## Project Description
This project is a simple movie recommendation system developed using Python. It recommends movies based on similarities between their genres using content-based filtering.

## Features
- Displays a list of available movies
- Accepts a movie name from the user
- Identifies movies with similar genres
- Ranks recommendations based on genre similarity
- Handles invalid movie names
- Supports repeated searches

## Technologies Used
- Python
- Visual Studio Code

## Recommendation Technique
Content-based filtering is used to compare the genres of movies. The system calculates genre similarity and recommends the top five matching movies.

## How to Run
1. Install Python.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the command:

```bash
python recommendation_system.py
```

## Conclusion
This project demonstrates how a simple recommendation system can suggest relevant movies based on user preferences and similarities between movie genres.
